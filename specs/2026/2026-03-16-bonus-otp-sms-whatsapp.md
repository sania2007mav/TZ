# ТЗ: Подтверждение списания бонусов (SMS и WhatsApp)

Дата: 2026-03-16

## ТЗ №1: SMS (smsc.kz)

### Цель
При списании бонусов на кассе операция подтверждается OTP-кодом, отправленным клиенту по SMS через smsc.kz.

### Функционал
- Генерация OTP (6 цифр) при попытке списания бонусов.
- Отправка OTP через smsc.kz.
- Ввод кода кассиром в РМК.
- Проверки: TTL (по умолчанию 120 сек), 3 попытки, ограничение повторной отправки.
- Успех — списание разрешено; ошибка — отказ.
- Логирование отправок и подтверждений.
- Настройки интеграции: логин/токен/sender/таймауты.

### Оценка
| Этап | Часы |
|---|---:|
| Анализ текущей логики РМК и бонусов | 3 |
| Изучение и проверка API smsc.kz | 5 |
| Проектирование OTP-процесса | 3 |
| Разработка в 1С (РМК + проверки + формы) | 8 |
| Интеграция smsc.kz (запросы/ошибки/ретраи) | 6 |
| Настройки и права | 2 |
| Журналирование | 3 |
| Тестирование + исправления | 6 |
| Документация и сдача | 2 |

**Итого по SMS: 38 часов**

## ТЗ №2: WhatsApp (GreenAPI)

### Цель
При списании бонусов на кассе операция подтверждается OTP-кодом, отправленным клиенту в WhatsApp через GreenAPI.

### Функционал
- Генерация OTP при списании бонусов.
- Отправка OTP через GreenAPI.
- Ввод и проверка OTP в РМК.
- Ограничения: TTL, число попыток, повторная отправка.
- Логирование статусов отправки и результата подтверждения.
- Настройки GreenAPI: instanceId, token, endpoint, таймауты.

### Оценка
| Этап | Часы |
|---|---:|
| Анализ процесса РМК/бонусов | 3 |
| Изучение GreenAPI и тестовые вызовы | 6 |
| Проектирование OTP для WA | 3 |
| Разработка в 1С (формы/проверки/блокировки) | 8 |
| Интеграция GreenAPI (отправка/обработка ошибок) | 7 |
| Настройки и безопасность токенов | 3 |
| Логирование и диагностика | 3 |
| Тестирование + стабилизация | 7 |
| Документация и передача | 2 |

**Итого по WhatsApp: 42 часа**
