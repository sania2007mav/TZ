# TZ

Репозиторий для хранения технических заданий.

## Структура

- `specs/<год>/` — файлы ТЗ (md, xlsx, docx, pdf)
- `specs/INDEX.md` — общий реестр ТЗ (автообновляемый)
- `scripts/update_specs_index.py` — генерация/обновление общего списка

## Как добавлять новое ТЗ

1. Положить файл ТЗ в папку `specs/<год>/` (рекомендуется дата в начале имени).
2. Обновить реестр:

   ```bash
   python3 scripts/update_specs_index.py
   ```

3. Закоммитить и запушить изменения.
